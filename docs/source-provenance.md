# Source provenance

## Current Engine boundary

Rusty D20 currently consumes the adjacent Rusty Engine public C# SDK and
generated product contract. The provider is selected by the local checkout,
is not a runtime/save identity, and is never modified or copied by this
repository. See [adjacent-engine-dependency.md](adjacent-engine-dependency.md).

## Authored C# content

`D20ContentCatalog` is the current executable content source. It contains
clean-room C# adaptations for the six-attribute/four-defense foundation, Steel
Guard, Ember Ward, The Warden's Gate, and Ember's Wake. Each module records a
stable source path, subject identity, and adaptation note through
`SourceProvenance` so compilation diagnostics and projections retain the
origin of product facts.

The retired Rust and TypeScript paths named by those records are historical
research and disposition evidence only. They are not build inputs, runtime
dependencies, generated artifacts, or a compatibility route.

## Donor disposition

The prior Rusty Engine UI donor and Ruleweaver/Asha material informed
presentation shape and bounded d20 vocabulary. Rusty D20 owns the resulting
values, labels, implementations, campaign policy, and projections. No donor
runtime code, broad content catalog, executable TypeScript rule behavior, or
provider implementation is carried forward.

The detailed file-by-file hard-cut rationale remains in
[csharp-migration-map.md](csharp-migration-map.md). That document is preserved
as historical migration/provenance evidence; current authority is the C#
source and the documents linked from this page.
